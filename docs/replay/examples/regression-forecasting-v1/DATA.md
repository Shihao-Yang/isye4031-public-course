# Data and reproduction

Lecture 17 uses 300 original constructed independent stores, seed 403117. Store sales and advertising are measured in thousands of dollars per month. See the generation code and design JSON for every variable and the mechanism. No actual business records are present.

Lecture 18 uses 168 sequential monthly daily-occupancy averages across four hotels, transcribed from Bowerman, O'Connell and Koehler, Forecasting, Time Series, and Regression, fourth edition, Table 6.4, printed page 297. Month 1 is January; actual calendar years are unspecified. These are not monthly totals. The last 12 months are reserved for evaluation, so the fitted results differ from the textbook's full-sample results. The instructor approved publication of this classroom package. Only the attributed numerical observations and original analysis are included; textbook pages and source figures are excluded.

These replays display completed calculations. Human prompts were simulated; Codex CLI generated and executed the code and wrote the preserved answers. Instructor notes are separate. Install requirements.txt in Python 3.12 and run reproduction-order.txt in a fresh folder containing the supplied data and scripts. Original recorded outputs should be kept separately.
