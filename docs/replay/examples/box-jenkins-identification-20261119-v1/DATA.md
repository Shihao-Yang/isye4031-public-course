# Paper-towel sales
Historical Olympia Paper Company teaching example from Bowerman, O’Connell and Koehler, Forecasting, Time Series, and Regression, fourth edition, Table 9.1, p. 403. The file contains 120 consecutive weekly observations. Calendar dates are unspecified. y is sales above 100,000 rolls, in units of 10,000 rolls. Actual rolls = 100000 + 10000*y. Negative y is valid and indicates sales below the baseline. The aim is to plan production, storage and budgets using future weekly sales forecasts. No future observed values are supplied. Use the four-decimal input values consistently; textbook output may reflect extra precision.
