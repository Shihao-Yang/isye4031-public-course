ISYE 4031 public course, Fall 2026

Statistics first. Agents in the workflow. Verification throughout.

Regression and Forecasting is being redesigned for a world in which students can work with capable coding agents. The mathematics remains central. What changes is the workflow: students plan, implement, test, audit, and defend their statistical decisions.

What students should learn

Model

Translate a real question into regression, statistical-learning, or forecasting structure.

Implement

Use agents and Python to build reproducible analyses rather than isolated code fragments.

Verify

Check assumptions, tests, residuals, leakage, uncertainty, calculations, and citations.

Communicate

Explain conclusions, limitations, and decisions clearly enough to withstand questions.

Why an AI-agent-first redesign?

AI can produce plausible code and polished explanations quickly. That does not make the statistical reasoning correct. The course therefore shifts attention from unaided syntax production toward the parts of analysis that remain scientifically decisive:

  • choosing the right target and data structure;
  • connecting mathematics to implementation;
  • designing checks that can reveal a wrong answer;
  • comparing models against transparent baselines;
  • documenting how agent output was accepted, changed, or rejected; and
  • defending the analysis without outsourcing understanding.

Core principle: An AI-generated answer is not evidence that an analysis is correct. Evidence comes from mathematics, diagnostics, tests, reproducibility, and appropriate validation.
