# 从相关关系到简单线性回归

## 学习目标

完成本节后，学习者应该能够：

1. 区分相关关系与条件均值模型；
2. 拟合并解释简单线性回归；
3. 把最小二乘与残差、样本协方差联系起来；
4. 使用 AI 编程智能体可复现地实现分析；
5. 利用数学恒等式和诊断问题审计实现。

## 1. 从统计模型开始

对于观测 ((x_i, y_i))，简单线性回归假设

\[
Y_i = \beta_0 + \beta_1 x_i + \varepsilon_i,
\qquad E(\varepsilon_i \mid x_i)=0.
\]

直线 \(\beta_0 + \beta_1 x\) 描述在给定 \(x\) 时 \(Y\) 的条件均值。它不会自动建立因果关系，也不能保证外推有效。

最小二乘选择 \(\hat\beta_0\) 和 \(\hat\beta_1\)，使下式最小：

\[
\sum_{i=1}^n \left[y_i-(b_0+b_1x_i)\right]^2.
\]

当模型包含截距时，

\[
\hat\beta_1 = \frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sum_i (x_i-\bar x)^2},
\qquad
\hat\beta_0 = \bar y-\hat\beta_1\bar x.
\]

## 2. 完成一个透明的五点示例

假设 \(x\) 是受控测试时间，单位为小时；\(y\) 是观测到的表现分数。

| 观测 | \(x\) | \(y\) |
| ---: | ---: | ---: |
| 1 | 1 | 2.2 |
| 2 | 2 | 2.8 |
| 3 | 3 | 4.2 |
| 4 | 4 | 4.7 |
| 5 | 5 | 6.1 |

在使用软件之前：

1. 画出数据草图，并预测斜率的正负；
2. 计算 \(\bar x\) 和 \(\bar y\)；
3. 计算最小二乘斜率和截距；
4. 使用 \(x\) 和 \(y\) 的单位解释斜率；
5. 解释为什么在 \(x=20\) 处预测比在 \(x=3.5\) 处预测更值得怀疑。

## 3. 请智能体实现、解释并测试

在干净的项目目录中，把数据和以下任务交给智能体：

> 拟合一个包含截距的简单线性回归。报告系数、拟合值和残差。绘制观测点和拟合直线。为最小二乘的核心恒等式编写测试。在具体语境中解释斜率，指出外推风险，并列出仅凭五个观测无法验证的假设。保证分析可复现，不要虚构额外数据。

项目必须包括：

- 可执行的分析脚本；
- 至少三个自动化检查；
- 保存的图形；
- 简短解释；
- 说明哪些内容由 AI 生成、哪些内容经过独立验证的 AI 使用记录。

## 4. 审计结果

对于包含截距的普通最小二乘，检查以下数值是否在计算误差范围内接近零或相等：

\[
\sum_i e_i = 0,
\qquad
\sum_i x_i e_i = 0,
\qquad
\bar{\hat y} = \bar y.
\]

然后追问：

- 实现是否包含截距？
- 系数的单位是否解释正确？
- 拟合直线是否通过 \((\bar x, \bar y)\)？
- 残差是否按观测值减拟合值计算？
- 图形使用的数据和模型是否与报告系数一致？
- 是否混淆了均值置信区间与个体预测区间？
- 因果或外推结论是否超出了数据支持的范围？

<details>
<summary>实现检查所需的参考值</summary>

对于这五个观测，最小二乘直线约为

\[
\hat y = 1.09 + 0.97x.
\]

由于舍入方式不同，数值显示可能略有差异。审计应该使用适当容差，而不是要求字符串完全相同。
</details>

## 5. 为分析答辩

学习者应该能够在不询问智能体的情况下回答：

1. 斜率估计的对象是什么？
2. 如果 \(x=0\) 不在观测范围内，为什么截距难以解释？
3. 哪个最小二乘恒等式能够帮助验证截距实现正确？
4. 需要什么证据才能提出因果结论？
5. 预测新观测值与预测条件均值有什么不同？

## 结束检查

写三句话：

1. 一句话陈述拟合关系；
2. 一句话陈述最重要的局限；
3. 一句话指出下一步最有信息量的诊断或数据收集工作。
