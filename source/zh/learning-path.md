# 解释、预测与实际预测运行

课程从统计基础开始，逐步进入回归和统计学习，最后讨论时间序列预测。每一部分都重复同一套工作流：建立基线、使用智能体、审计结果，并说明哪些结论值得信任。

## 第一部分：统计与回归基础

- 抽样变异、不确定性、置信区间和假设检验
- 简单与多元线性回归
- 最小二乘、解释、残差和诊断
- 变量变换、模型构建和变量选择
- 可复现实现和回归审计

**公开示例：**[从相关关系到简单线性回归](sample-lesson.html)

## 第二部分：统计学习

- 逻辑回归和分类指标
- 岭回归和 LASSO
- 交叉验证、调参与模型比较
- 主成分分析
- 支持向量机和核方法

学生不能只问模型是否成功拟合，还要判断验证方案是否对应真实部署问题。

## 第三部分：预测

- 时间序列回归
- 指数平滑
- ARIMA 模型
- 预测评估、不确定性和实际运行约束

预测被视为一个决策过程。一个真正有用的预测必须说明目标、发布时间、预测范围、可用信息集、不确定性和评估协议。

## 整个学期反复追问的五个问题

1. 目标究竟是什么？
2. 做出预测时可以使用哪些信息？
3. 哪些假设把数据与模型连接起来？
4. 哪个基线和哪些测试能够暴露失败？
5. 需要什么证据，才能把结果用于决策？
