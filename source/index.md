## What students should learn

<div class="card-grid">
<article class="card"><h3>Model</h3><p>Translate a real question into regression, statistical-learning, or forecasting structure.</p></article>
<article class="card"><h3>Implement</h3><p>Use agents and Python to build reproducible analyses rather than isolated code fragments.</p></article>
<article class="card"><h3>Verify</h3><p>Check assumptions, tests, residuals, leakage, uncertainty, calculations, and citations.</p></article>
<article class="card"><h3>Communicate</h3><p>Explain conclusions, limitations, and decisions clearly enough to withstand questions.</p></article>
</div>

## Why an AI-agent-first redesign?

AI can produce plausible code and polished explanations quickly. That does not make the statistical reasoning correct. The course therefore shifts attention from unaided syntax production toward the parts of analysis that remain scientifically decisive:

- choosing the right target and data structure;
- connecting mathematics to implementation;
- designing checks that can reveal a wrong answer;
- comparing models against transparent baselines;
- documenting how agent output was accepted, changed, or rejected; and
- defending the analysis without outsourcing understanding.

<div class="callout">
<p><strong>Core principle:</strong> An AI-generated answer is not evidence that an analysis is correct. Evidence comes from mathematics, diagnostics, tests, reproducibility, and appropriate validation.</p>
</div>

## Begin with one complete lesson

The first public lesson moves from association to simple linear regression. It asks students to fit a model, interpret the slope in context, inspect residuals, use an agent to reproduce the analysis, and audit the result against mathematical identities.
